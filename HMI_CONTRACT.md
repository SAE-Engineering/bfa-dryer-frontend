## Architecture (final PLC)

- 4 drives on the M221's built-in Modbus Serial IOScanner (19200 8E1, slaves 1-4):
  trace chain `%DRV0` (s1, ATV12), agitator 1 `%DRV1` (s2, ATV12), agitator 2
  `%DRV2` (s3, ATV12), spinner `%DRV3` (s4, ATV320 3 kW).
- Hot fan = plain start/stop coil `%Q0.0` (fixed speed, 10 V analog bridge).
- DOL bank `%Q0.4-0.8` (mill / disch-conv / load-conv / brush / shaker).
- Discharge agitator = plain run/stop coil `%Q0.1`.
- Burner = automatic 2-stage hysteresis off the burner-air PT100 (`%Q0.2/0.3`).
- Safety: hardware safety relay + `%Q0.9` PLC e-stop enable from `%I0.13`, and a
  software e-stop ANDed into every run permit.

## Register map (UMAS func 0x24 read / 0x25 write; single TCP, no reservation)

### Commands — HMI writes (`%MW0` read-modify-write via UMAS set_bit)
- `%MW0` = command word.  Bit k (`%MW0:Xk`) = on/off request for cmd_bit=k.
- Drive **Hz** speed setpoints (HMI writes via `/api/speed`, scaled 0-100 % →
  0-50 Hz): `%MW40` spinner, `%MW41` ag1, `%MW42` ag2, `%MW43` trace.
- `%MW44` hot-fan speed (display-only, 0-100 %).
- Burner operator setpoints (°C ×10): `%MW45` target, `%MW46` band,
  `%MW49` product scorch trip.

### Status / temps — HMI reads
- **Temps (°C ×10)** — read `%MW31-34` **directly** (the PLC mirrors `%IW1.x` →
  `%MW3x` each scan): `%MW31` burner-air, `%MW32` product1, `%MW33` product2,
  `%MW34` exhaust.  (`%MW30` hot-fan motor is NOT wired on the final program →
  reads 0; logged only.)
- **Safety** — read `%M4` via UMAS 0x24 **object class 0x02** (`%M` memory bit;
  see UMAS access note below).  `%M4` mirrors `%I0.13` (active-HIGH = safety OK).
  Replaces the old hardcoded `safety_ok=True`.
- **Faults** — read `%M20/21/22` via the same `%M` path → fault annunciation:
  `%M20` FIRE-TRIP (force fan off), `%M21` OVER-TEMP (burner cut),
  `%M22` SCORCH (burner cut).
- **fan_proven** — derived from the PLC hot-fan-on demand bit `%M23` (status),
  NOT the `%MW0:X0` command bit.

Speeds displayed = **commanded** (the Hz the HMI last wrote).  Actual-RPM via the
ATV IOScanner read words (`%IWN10x` RFRD) is **deferred to phase 2**.

### SAFETY registers — NOT operator-settable from the HMI (first-scan only)
`%MW47` over-temp trip (98.0), `%MW48` re-enable (95.0), `%MW51` fire limit
(120.0), `%MW52` fire re-enable (110.0).

## UMAS access — reading `%M` bits

The backend's UMAS client reads `%MW` with func `0x24` object class `0x03`.  The
**`%M` (memory bit) object class is `0x02`** — confirmed byte-for-byte from MEB
animation-table captures 2026-06-15 (`%M0/1/2/199` read with class 0x02, 1-byte
bit values).  `read_bits([...])` issues a class-0x02 `0x24` burst and decodes each
item's bit.  Reads use pairing `0x00` (no reservation), so the runtime poll path
is unaffected by the `BFAplc` read-protect (which gates `0x28` program upload).

## Backend (FastAPI) requirements
- Config: `PLC_HOST`, `PLC_PORT=502`, `PLC_PROTO=umas|modbus`, `POLL_MS=500`,
  `PLC_SIM=true|false`, `LOG_DIR=/data`, `LOG_INTERVAL_S=5`.  See
  `backend/.env.panel.example` for the live panel profile.
- Poll loop every POLL_MS: read `%MW0,31-34,45,46,49` (one 0x24 burst) **plus**
  `%M4,20,21,22,23` (one 0x24 class-0x02 burst) → build State → broadcast over WS.
- Commands: `POST /api/command {id, on}` → `set_bit` on `%MW0`.
  `POST /api/speed {id, value_pct}` → write the Hz/pct setpoint (scaled by unit).
  `POST /api/burner_setpoint {celsius}` → write `%MW45`.
  `POST /api/setpoint {key, value_c}` → write `%MW45/46/49`.
- `GET /api/health`, `GET /api/state`.
- **Data logging:** every LOG_INTERVAL_S append a row to
  `${LOG_DIR}/bfd_log_YYYY-MM-DD.csv` (ts, per-component running, per-VSD speed,
  temps, fan_proven, safety_ok).
- **PLC_SIM mode:** in-process fake register bank; the whole HMI works with no
  hardware for dev/demo.  Default `PLC_SIM=true` until on-site.
- Resilience: if the PLC is unreachable, keep serving (connected=false), retry;
  never crash.

## Frontend (React) requirements
- Dark theme (default).  Big, touch-friendly tiles.
- **Status bar:** connection, SIM badge, Safety OK, Fan proven, logging, clock,
  PLC release/reconnect.  **Fault summary banner** (amber/red) listing active
  faults; clears when none.
- **Component grid:** tile per component — label, ON/OFF toggle (POST /api/command),
  running LED, fault LED (wired to the `faults` data).  has_speed → speed setpoint
  modal (POST /api/speed) + speed readout.
- **Temps panel:** Burner, Product 1, Product 2, Exhaust (Hot-fan motor logged
  only) in °C, 1 decimal.
- **VSD reference modals:** Nameplates + Commissioning Programs (read-only — the
  HMI never writes drive parameters).
- Live updates via `useWebSocket` + Zustand.
